THE FUCKIN WEATHER — PERSONALITY EDITION

Upload index.html, style.css, app.js, weather-effects.js to your GitHub Pages repository root.

New: live-condition personality comments, hourly commentary and an Another Fuckin Take button. The commentary is generated from the weather forecast, not official safety warnings.

No default city, no visible numeric temperatures, location requested only with permission. Open-Meteo internet access required.

UNIT SWITCH PRANK:
- Default Fahrenheit.
- First tap on Celsius: humorous message and stays Fahrenheit.
- Second tap on Celsius: Yes/No confirmation.
- Yes shows Celsius selected; No returns Fahrenheit.
- No numerical temperatures are shown anywhere, so the weather scale and forecasts remain unchanged; the unit selector indicates preference only.
